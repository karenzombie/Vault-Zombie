# VaultZombie Question Bank: Marriage (Wedding) Vault

For a wedding (guests predict the couple's married life). This is the template the other nine banks follow: the same three-level structure, the same four answer types, the same table layout.

## How to read this

- **Three levels:** Vault type (Marriage) > Sub-category (8 below) > Questions.
- **Answer type** is fixed per question. Four types:
  - **Number:** guest enters a figure.
  - **Name-pick:** guest picks one of the two people. "Partner A" and "Partner B" are placeholders that resolve to the couple's actual names at setup. Some name-picks add "Both" or "Neither" as extra options, noted in the Options column.
  - **Multiple choice:** guest picks from the defined options listed.
  - **Free text:** guest types an answer, hard-capped at 140 characters.
- **No reveal date is attached to a question.** The operator picks one reveal schedule at vault setup (Weekly Sprint, Monthly x3, Monthly Year, Half-then-Annual, or Annual Keepsake), and that schedule produces the vault's reveal dates. When a guest answers, they pick one of those dates for each answer. See the master build brief, section 4.
- Everything here is seed content. All of it is editable, reorderable, and expandable from the admin panel without code changes.

**Count:** 112 questions across 8 sub-categories (14 each).
