# Vault Zombie: Email Spec Addendum 2

**Applies to:** `VaultZombie-Email-Spec.md`
**Date:** September 12, 2026

Read both documents. Where this addendum covers something, it governs. Everything else in the email spec is unchanged, including all other copy in section 6 and everything in Email Spec Addendum 1.

---

## A1. Why this changed

Gift redemption asked the recipient to sign in first and enter the code second. That order lost the code whenever someone signed up during redemption, and it left a paid-for host looking at a page selling them a vault they already had.

Redemption now runs in this order: enter the code, then sign in or sign up, then land in vault setup. Both gift emails described the old order, so both change.

---

## A2. F2, the recipient's email

Section 6, F2 "Gift for recipient," the numbered steps under **How to redeem it**. Read them now as:

1. Go to [redeem link]
2. Enter your code
3. Sign in, or sign up for a free account
4. Your [tier] vault is ready to set up

---

## A3. F1, the purchaser's email

Section 6, F1 "Gift purchase," the numbered steps under **How they redeem it**. Read them now as:

1. They go to [redeem link]
2. They enter the code
3. They sign in, or sign up for a free account
4. Their [tier] vault is ready to set up

---

## A4. Nothing else in either email changes

Subject lines, eyebrows, headings, paragraphs, code boxes, highlight bands, stat tiles, receipt rows, buttons, icons, and footers all stand exactly as written in section 6. No other email is affected.
