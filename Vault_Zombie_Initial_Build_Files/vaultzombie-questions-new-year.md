# VaultZombie Question Bank: New Year / Year Ahead Vault

For a New Year's party or any "year ahead" gathering (guests predict how a coming year will go for someone). Single subject, so it leans on number, multiple choice, and free text. Every prompt names the year it is about with the `[Year]` token, so this type works on any reveal schedule: on Monthly x3 or Monthly Year it is a fast game about the year just starting, and on Half-then-Annual or Annual Keepsake the same prompts ask about each of the next several years in turn.

## How to read this

- **Three levels:** Vault type (New Year / Year Ahead) > Sub-category (8 below) > Questions.
- **Placeholders:** "[Person]" resolves to the subject's name at setup. (This type also works as a group vault, run once per person.) "[Year]" resolves to a calendar year, computed per reveal date by the app: for a reveal that lands on January 1, it is the year that just ended; for any other reveal date, it is the year the reveal date falls in. A vault anchored January 1, 2027 on an annual schedule shows "in 2027" for its first reveal, "in 2028" for its second, and so on. See the master build brief, section 9.
- **Answer type** is fixed per question. Three used here:
  - **Number:** guest enters a figure (a count, a number of months).
  - **Multiple choice:** guest picks from the defined options listed.
  - **Free text:** guest types an answer, hard-capped at 140 characters.
  - (Name-pick is not used in this single-subject type. It can be added from the admin panel if you ever want one.)
- **No reveal date is attached to a question.** The operator picks one reveal schedule at vault setup (Weekly Sprint, Monthly x3, Monthly Year, Half-then-Annual, or Annual Keepsake), and that schedule produces the vault's reveal dates. When a guest answers, they pick one of those dates for each answer. See the master build brief, section 4.
- All content is editable, reorderable, and expandable from the admin panel without code changes.

**Count:** 96 questions across 8 sub-categories (12 each).
